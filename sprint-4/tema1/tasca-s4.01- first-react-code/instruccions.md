**Primer Projecte React amb TypeScript** 

En aquesta activitat, instal·laràs les eines necessàries i crearàs la primera aplicació React amb TypeScript utilitzant Vite. 

**Objectiu**   
»Configurar l'entorn de desenvolupament de React.   
»Crear una nova aplicació React amb TypeScript.   
»Entendre l'estructura bàsica d'un projecte React.   
»Executar l'aplicació i veure-la al navegador.   
»Utilitzar el tutorial de Scrimba com a suport d'aprenentatge. 

**Passos a seguir Instal·lar Node.js:** 

Si encara no el tens, descarrega i instal·la la versió LTS des de la web oficial de Node.js. 

Verifica la instal·lació amb node \-v i npm \-v a la terminal. 

**Crear un nou projecte React amb TypeScript:** 

A la terminal, executa: npm create vite@latest meu-primer-react \-- \--template react-ts. 

Instal·la les dependències npm install. 

Explorar l'estructura del projecte: 

- Obre la carpeta meu-primer-react amb el teu editor de codi i familiaritza't amb els fitxers principals (src/main/tsx, src/App.tsx, index.html, package.json, tsconfig.json).   
- Executar l'aplicació: A la terminal, navega dins la carpeta del teu projecte (meu-primer-react) i executa: npm run dev. Observa l'aplicació al navegador.   
- Seguir el tutorial de Scrimba: Utilitza el següent recurs com a guia d'aprenentatge: Learn React i completa les respostes. al repositori de github.
