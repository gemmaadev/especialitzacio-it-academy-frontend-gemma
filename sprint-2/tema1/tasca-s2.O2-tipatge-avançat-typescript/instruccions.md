### **Tipatge avançat en TypeScript**

Aquest exercici et permetrà practicar conceptes avançats de tipatge en TypeScript. Treballaràs amb errors comuns de tipatge, funcions asíncrones, manipulació d'objectes i altres característiques del sistema de tipus de TypeScript.

#### **Objectiu**

* » Resoldre errors d'any implícit.  
* » Dominar tipatges d'objectes i paràmetres opcionals.  
* » Treballar amb arrays i unions de tipus.  
* » Tipar funcions síncrones i asíncrones.  
* » Utilitzar tipus avançats com Omit, Pick i ReturnType.  
* » Gestionar errors en blocs try-catch.  
* » Aplicar utilitats de tipus com Record i Extends.

#### **Passos a seguir**

1. Preparació del entorn:

\# Clonar el repositori  
git clone https://github.com/it-academy-front-end/it-sprint2-ts

\# Accedir al directori del projecte  
cd it-sprint2-ts

\# Instal·lar dependències  
npm install  
 

2. Executar els tests:

\# Executar tots els tests  
npm test

\# Executar un laboratori específic (ex: 01\)  
npm run exercise 01  
 

3. Resoldre els laboratoris:  
   * » Obre el projecte a VS Code: code .  
   * » Navega a la carpeta src i resol cada fitxer .problem.ts  
   * » Consulta els errors als tests i a l'editor  
   * » Utilitza la documentació oficial de TypeScript com a referència  
4. Verificar solucions:  
   * » Cada vegada que guardis canvis, els tests es reexecutaran automàticament  
   * » Els comentaris // @ts-expect-error indiquen on s'esperen errors de tipatge
