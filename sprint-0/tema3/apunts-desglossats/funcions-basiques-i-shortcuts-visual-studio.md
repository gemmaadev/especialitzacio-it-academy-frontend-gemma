## **VS Code: l'editor que usaràs cada dia**

Visual Studio Code (VS Code) és l'editor de codi més popular del món. És gratuït, de codi obert, funciona a Windows, macOS i Linux, i és el que trobaràs en pràcticament tots els tutorials i empreses de desenvolupament web. No cal configurar res especial per començar: simplement l'instal·les des de `code.visualstudio.com` i ja pots obrir fitxers i carpetes.

**La interfície: les cinc zones principals**

La interfície de VS Code consta de cinc àrees principals. La **Activity Bar** és la columna vertical a l'esquerra que serveix com a navegació principal, amb icones per a l'explorador de fitxers, la cerca, el control de versions Git, la depuració i les extensions. 

La **Primary Side Bar** mostra informació contextual quan selecciones una vista. 

L'**Editor** ocupa l'àrea central on passaràs la major part del temps codificant. 

El **Panel** a la part inferior conté el terminal integrat i els registres de sortida.

A la part inferior trobaràs també la **barra d'estat**, que mostra informació de l'arxiu actual (branca de Git, errors, codificació, tipus de fitxer) i on pots clicar per fer canvis ràpids.

**La Command Palette: l'eina més important**

La combinació de tecles més important que has de saber és `Ctrl+Shift+P` (o `Cmd+Shift+P` al Mac), que obre la Command Palette. Des d'aquí tens accés a totes les funcionalitats de VS Code, incloses les dreceres de teclat per a les operacions més habituals.

La Command Palette té diversos modes:

* Escriu `>` per buscar **comandes** (per exemple, `> format document`)  
* Elimina el `>` per buscar **fitxers** del projecte per nom  
* Escriu `#` per buscar **símbols** com variables o funcions al codi

La majoria de coses que necessitaràs fer a VS Code les pots trobar aquí escrivint-ne el nom en anglès, sense necessitat de memoritzar tots els menús.

**El terminal integrat**

VS Code incorpora un terminal directament a l'editor. Pots obrir-lo amb ```Ctrl+`` (la tecla de l'accent greu, la que hi ha a l'esquerra del``` 1\`) sense necessitat de canviar de finestra. Això és especialment útil perquè pots escriure codi i executar comandes al terminal sense sortir de VS Code.

Pots obrir múltiples terminals a la vegada i alternar entre ells des del desplegable que apareix a la dreta del panell del terminal.

**Dreceres de teclat essencials**

Aprendre les dreceres de teclat és el que marca més la diferència en productivitat. No cal aprendre-les totes de cop: comença per les que uses més sovint i afegeix-ne de noves progressivament.

**Generals (les més importants):**

| Acció | Windows / Linux | macOS |
| ----- | ----- | ----- |
| Command Palette | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Obrir fitxer ràpid | `Ctrl+P` | `Cmd+P` |
| Mostrar/amagar sidebar | `Ctrl+B` | `Cmd+B` |
| Terminal integrat | \`Ctrl+\`\` | \`Ctrl+\`\` |
| Nou terminal | \`Ctrl+Shift+\`\` | \`Ctrl+Shift+\`\` |
| Guardar | `Ctrl+S` | `Cmd+S` |

**Edició de codi:**

| Acció | Windows / Linux | macOS |
| ----- | ----- | ----- |
| Comentar línia | `Ctrl+/` | `Cmd+/` |
| Moure línia amunt/avall | `Alt+↑ / Alt+↓` | `Option+↑ / Option+↓` |
| Copiar línia amunt/avall | `Shift+Alt+↑ / ↓` | `Shift+Option+↑ / ↓` |
| Esborrar línia | `Ctrl+Shift+K` | `Cmd+Shift+K` |
| Autocompletat | `Ctrl+Space` | `Ctrl+Space` |
| Formatar document | `Shift+Alt+F` | `Shift+Option+F` |

**Navegació:**

| Acció | Windows / Linux | macOS |
| ----- | ----- | ----- |
| Anar a definició | `F12` | `F12` |
| Buscar al fitxer | `Ctrl+F` | `Cmd+F` |
| Buscar a tot el projecte | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Canviar entre fitxers oberts | `Ctrl+Tab` | `Ctrl+Tab` |

Pots obtenir un PDF amb totes les dreceres de teclat seleccionant "Help: Keyboard Shortcut Reference" a la Command Palette.

**Personalització bàsica**

VS Code es pot adaptar completament als teus gustos. Des de la Command Palette pots canviar el tema de colors (`> Color Theme`), la mida de la lletra (`> Increase Font Size`) o qualsevol altra configuració. Tot queda desat automàticament i es recupera la propera vegada que obres l'editor.

Cada vegada que inicies VS Code, s'obre en el mateix estat en què el vas tancar: la carpeta, el disseny i els fitxers oberts es preserven. Això fa que sigui molt còmode reprendre la feina exactament d'on ho havies deixat.
