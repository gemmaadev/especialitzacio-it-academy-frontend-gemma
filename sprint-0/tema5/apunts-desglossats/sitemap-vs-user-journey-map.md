## **Sitemap vs. User Journey Map: quan usar cada un**

Explicació de què és un sitemap i per a què serveix.

**Com definir un user journey map**  
[https://www.coursera.org/mx/articles/creating-user-journey-maps-a-guide](https://www.coursera.org/mx/articles/creating-user-journey-maps-a-guide)

**Què és un Sitemap?**

Un sitemap visual és una eina que descriu l'estructura del contingut i les pàgines d'un lloc web en format gràfic. És com un mapa de la pàgina web que guia tant els visitants com els motors de cerca per navegar pel lloc. Ofereix una vista d'ocell de l'estructura d'un lloc web, mostrant totes les pàgines i les seves interconnexions.

Pensa-hi com un plànol d'un edifici: no et diu com et sentiràs movent-te per dins, però sí et mostra quines habitacions hi ha, en quin ordre estan i com estan connectades entre elles.

**Què és un User Journey Map?**

Un user journey map ofereix una representació visual de l'experiència del client. Aquesta visualització pot abastar tota la relació d'un client amb una marca o centrar-se en una experiència concreta en interactuar amb una aplicació o lloc web. Els user journey maps són una eina útil per comprendre les necessitats i els punts febles dels usuaris i, en última instància, per optimitzar l'experiència d'usuari.

Si el sitemap és el plànol de l'edifici, el user journey map és el relat de com una persona concreta entra a l'edifici, on va, com se sent a cada habitació i on s'encalla o es perd.

**Els elements d'un User Journey Map**

Els elements principals que sol tenir un user journey map són la **persona** (quin segment d'usuaris s'intenta comprendre), l'**escenari** (quina interacció es descriu), les **etapes del viatge** (les fases de l'escenari), les **accions de l'usuari** (què fa en cada etapa), les **emocions i pensaments** (com se sent i què pensa en cada moment) i les **oportunitats** (on pot millorar l'experiència).

**La diferència clau**

El **sitemap** respon a la pregunta: *"quines pàgines existeixen i com estan organitzades?"* És un diagrama d'**estructura**.

El **user journey map** respon a la pregunta: *"com viu l'usuari la seva interacció amb el producte?"* És un diagrama d'**experiència**.

Un parla de l'arquitectura del sistema. L'altre parla de les emocions, accions i friccions de la persona que l'usa.

**Quan usar un Sitemap**

Un sitemap és especialment útil en aquests escenaris: quan es planifica un lloc web nou des de zero, perquè ajuda a exposar les idees i crear una estructura clara abans d'avançar amb el disseny; quan es crea un pla de continguts, per identificar llacunes i assegurar que es cobreixen tots els temes necessaris; i quan es reorganitza un lloc web existent, per veure com encaixa tot abans de fer canvis.

En resum, usa el sitemap quan la pregunta principal és **d'arquitectura i organització**: quantes pàgines necessitem, com s'anomenen, com estan connectades entre elles i quina és la jerarquia de navegació. És la primera cosa que cal fer en un projecte web nou, en la fase de planificació, quan encara no s'ha dissenyat res.

**Quan usar un User Journey Map**

Crear un user journey map és útil perquè fomenta una mentalitat centrada en l'usuari, centrant-se en com pot pensar i sentir un usuari mentre utilitza el producte; crea una visió compartida per a l'equip; i pot descobrir punts cecs, revelant fallades de disseny o noves oportunitats que no s'havien considerat.

Usa el user journey map quan la pregunta principal és **d'experiència i empatia**: com se sent l'usuari en cada pas, on s'encalla, on abandona el procés i on podries millorar la seva experiència. És especialment útil quan ja tens una estructura (sitemap) i vols validar que funciona bé per a les persones reals que l'usaran.

**La regla pràctica: quin va primer?**

En general, el **sitemap** va primer i el **user journey map** va després. Primer defineixes quines pàgines i seccions existiran (sitemap), i després analitzes com l'usuari les recorrerà i com se sentirà fent-ho (user journey map).

Però de vegades és al revés: si comences per entendre bé les necessitats i el recorregut de l'usuari (journey map), pots descobrir que necessites pàgines que no tenies previstes al sitemap, i has de tornar enrere i actualitzar-lo.

**Resum comparatiu**

|  | Sitemap | User Journey Map |
| ----- | ----- | ----- |
| Respon a... | Quines pàgines existeixen? | Com viu l'usuari el producte? |
| Perspectiva | Estructura del sistema | Experiència de la persona |
| Conté | Pàgines, seccions, jerarquia | Etapes, accions, emocions, friccions |
| S'usa per... | Planificar l'arquitectura | Detectar problemes d'experiència |
| Fase del projecte | Fase inicial de planificació | Fase d'anàlisi i disseny UX |
| Útil per a... | Devs, arquitectes d'informació | Dissenyadors UX, product managers |
