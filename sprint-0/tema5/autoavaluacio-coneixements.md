Respon aquestes preguntes als teus apunts per fixar coneixements i identificar dubtes:

1. **Saps dissenyar un sitemap d'un projecte web?**

Sé que un sitemap representa la jerarquia de pàgines d'un lloc web amb nodes i connexions. He après a definir nivells, afegir URLs a cada node, indicar el contingut de cada pàgina, diferenciar pàgines públiques de privades amb colors... A més, com a web project manager ja havia estructurat sitemaps (esquemes web) per clients, i ara entenc millor com documentar-los tècnicament per als developers.

2. **Saps usar diagrams com user-flows o diagrames de seqüencia per dissenyar la lògica de l'aplicació ?**

He après els conceptes bàsics. He creat un diagrama de flux del registre d'usuaris amb les formes estàndard (oval per inici/fi, rectangle per operacions, rombe per decisions), camins alternatius i sistema de reintents.

Entenc la diferència entre el happy path i els camins d'error, i sé identificar on pot fallar un flux. Com a àrea de millora, m'agradaria practicar més els diagrames de carrils per separar les accions per capes (client, navegador, servidor) i aprofundir en diagrames de seqüència per a fluxos més complexos.
